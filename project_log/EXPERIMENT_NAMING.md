# 실험 ID와 제출 파일명

사용자 정정에 따라 AS는 실제 제출 ZIP 파일명에만 사용한다. 미제출 실험을 AS-07·AS-08로 기록한 것은 잘못된 표기였다.

| 작업 | 현재 실험 ID |
|---|---|
| 자모 점수 분리 비교 | JAMO-SCORE-01, JAMO-SCORE-02 |
| 합성 발음 생성 | KO-DIVERSE-PILOT01, KO-DIVERSE-01 |
| 추가 발음 역검색 검사 | KO-OWNERSHIP-01 |
| 사전별 매칭 비교 | EVAL-KO-DIVERSE-01, EVAL-KO-OWNERSHIP-01 |
| 실제 제출 결과 | SUB-115506 — 파일명 submit_AS-06.zip |

정정은 이름과 참조 경로만 변경한다. 원래 실행 명령, 측정값, 분할·설정·결과는 보존했다. 별칭 목록과 경로 매핑은 EXPERIMENT_NAMING.json에 있다. 정정 전 원본 JSON과 소스는 naming_history에 해시와 함께 보존했다. 역사적 자산 내부의 옛 ID는 당시의 잘못된 별칭이며 새 제출 파일을 뜻하지 않는다.

현재 실험 목록은 experiments/INDEX.csv를 따른다. 별칭과 현재 ID를 서로 다른 실험으로 중복 집계하지 않는다. 기존 submit_AS-06.zip 제출 ID115506·점수0.9122153056 및 해당 기준 자산은 변경하지 않았다.
