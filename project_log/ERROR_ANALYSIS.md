# 기존 베이스라인 오류 기록

최신 E004/E005의 오류 수정·새 오류·대표 사례는 [선박명 개선 결과](../docs/NAME_IMPROVEMENT_RESULTS.md)에 추가했다. 아래는 기존 E001의 오류 근거를 보존한 기록이다.

이후 n-gram을 추가한 E007/E008의 최신 변화는 [검색 조합 결과](../docs/RETRIEVAL_COMBINATIONS.md)를 확인한다. 기존 SPT 대비 선택 SNPT의 새 선박 오류는 8→5행, 11→10행이지만 새 오류도 각각 1행·2행 발생했다.

출처: E001의 공개 train 선박 그룹 보류 2,400행. 저장된 예측과 원래 validation_model/assets.json으로 후보 존재 여부를 다시 확인했다. 새 모델 학습·비공개 테스트 분석이 아니다.

총 오분류 16행, 오류가 있는 선박 7척이다. 후보 검색 누락은 2행, 후보 선택 오류는 14행이다. 같은 선박의 반복 기록을 독립적인 다양한 실패 사례처럼 과장하지 않는다.

| 입력 이름 | 정답 | 기존 예측 | 행 수 | 확인한 오류 단계 |
|---|---|---|---:|---|
| HAFNIA WREN | BW Wren | Hafnia Raven | 1 | 검색 누락 |
| 레지슬레이터 | Legislator | Secreto | 1 | 검색 누락 |
| 모닝 컴포저 | Morning Composer | Morning Cello | 4 | 후보 선택 |
| 베마그레이스 | Vemagrace | ABC Sun | 4 | 후보 선택 |

| 씨에스 오션 | CS Ocean | CS Hana | 4 | 후보 선택 |
| 할사이언 | Halcyon | Arsan | 1 | 후보 선택 |

## 확인된 사실과 가설

- **확인:** 검색 누락 사례에서는 현재 검색 결과에 정답 ID가 없다. 분류기만 바꿔서는 해당 후보를 선택할 수 없다.
- **가설:** HAFNIA WREN/BW Wren은 접두어 차이, 레지슬레이터/Legislator는 음역 차이를 더 잘 처리하면 검색을 개선할 가능성이 있다. 실제 선박명 변경 이력을 확인한 것은 아니다.
- **확인:** 나머지 사례에서는 정답 후보가 검색됐지만 다른 후보가 1위로 선택됐다.
- **가설:** Morning·Sky·CS 같은 공통 접두어보다 이름의 다른 부분을 더 정밀하게 비교하거나 유사 오답을 학습하는 방법을 검토할 수 있다. 현재 기록만으로 개별 특징이 오답을 일으켰다고 단정하지 않는다.

## 이후 개선 실험에서 남길 정보

입력의 공개 제원, 정답·오답 후보의 제원과 상위 점수, 후보 수, 정답 포함 여부, 변경 전후 순위·정오 여부를 같은 조건으로 기록한다. 현재 파일에 없는 후보 점수나 순위를 추정해서 채우지 않는다. 개선을 보고 다시 조정한 보류 결과는 모델 선택용 검증으로 표시한다.

원시 사례는 baseline_errors.json에 있다. 재현 명령은 다음과 같다.

```bash
python project_log/recheck_errors.py --artifacts-root /workspace/vessel_matching
```

위 경로는 현재 작업 환경의 원본 자산 위치이다. 다른 환경에서는 공식 데이터와 기존 분할의 예측·검증 자산이 있는 경로를 지정한다. 비공개 test.csv나 평가 서버의 개별 예측을 이 스크립트에 넣지 않는다.
