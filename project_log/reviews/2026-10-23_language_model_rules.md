# 공개 언어모델 사용 규정 확인

확인일: 2026-10-23 KST. 사용자 요청에 따른 문서 검토이며 학습·설치·모델 다운로드·ZIP 생성·운영진 문의 전송은 하지 않았다. 모델별 대회 운영진 승인을 받은 것은 아니다.

## 공식 출처

- 대회 규칙: https://dacon.io/competitions/official/236771/overview/rules
- 평가·실행 규격: https://dacon.io/competitions/official/236771/overview/evaluation
- Qwen Base: https://huggingface.co/Qwen/Qwen3.5-2B-Base

- Gemma 공식 라이선스: https://ai.google.dev/gemma/apache_2

## 확인된 사실

규칙은 공개된 범용 사전학습 가중치를 허용하며, 참가자의 추가 학습·검증 자료를 공식 train.csv와 vessel_catalog.csv로 제한한다. 외부 선박 DB·별도 입출항 기록·외부 정답 또는 매핑표는 금지된다. 열람한 규칙 본문에는 특정 모델 명단이나 모델 공개일 제한, Instruct 모델 일괄 금지가 없다.

Qwen3.5-2B-Base 모델 카드 첫 설명은 사전학습 전용 가중치와 파인튜닝 용도를 명시한다. 같은 카드의 Model Overview에는 Pre-training & Post-training 문구도 있어 상세 이력을 완전히 검증했다고 주장하지 않는다. Qwen3.5-2B는 후학습 모델이라고 명시한다. Gemma 4는 범용 다국어 모델로 사전학습 및 지시학습 변형을 공개한다고 설명한다. 이들은 범용 공개 가중치 후보라는 해석이 가능하지만 운영진이 모델별 사용을 승인했다는 뜻은 아니다. 일반 범용 사전학습 자료와 참가자가 추가 학습에 반입하는 외부 자료를 구분한다.

Qwen과 Gemma 4의 확인한 공식 자료는 Apache-2.0을 명시한다. 라이선스 준수와 대회 데이터 규정 준수는 별개다. 배포 시 해당 체크포인트에 적용되는 라이선스·저작권 고지와 NOTICE가 있으면 이를 보존해야 한다. 커뮤니티 파생 체크포인트는 원본과 별도로 추가 학습 이력을 확인해야 한다.

평가 페이지에서 ZIP 10GB, 해제 후 32GB, 설치 10분, 추론 전체 30분, L4 22.4GiB, RAM 26GB, Python 3.11.17, torch 2.7.1+cu128, transformers 4.57.6을 확인했다. 추론 중 인터넷 사용은 불가하다. 기본 패키지 활용은 권고이며 다른 버전 사용 시 설치 오류 가능성을 안내한다. 버전 변경을 명시적 금지로 해석하지 않는다.

## 적용 판단과 미검증 항목

- 공식 공개 가중치로 시작하고 공식 두 데이터만으로 파인튜닝하는 방식은 규칙 문구상 허용 범위에 부합하는 후보로 판단한다. LoRA도 추가 학습 데이터 제한을 동일하게 따른다.
- Qwen3.5·Gemma 4는 최신 런타임을 안내하므로 기존 패키지에서의 직접 실행, 설치 시간, 패키지 충돌, L4 메모리, 실제 ZIP 용량 및 처리 시간은 미검증이다. 현재는 제출 적합성 확인 완료로 표시하지 않는다.
- 모델 가중치·토크나이저·설정 등 추론 자산은 로컬 번들로 준비해야 한다. 다른 test 행을 문맥에 넣거나 대화 이력을 누적해서는 안 된다. 생성 난수와 배치에 따른 최종 ID 변동도 행 독립 검사 대상이다.
- LLM이 만들어 낸 선박 사실·별칭·정답 매핑을 별도 학습 정답으로 사용하는 방안을 허용된 것으로 단정하지 않는다. 공식 입력의 표기 변형과 새 지식·정답 생성은 구분해야 하며, 열람한 공식 규칙에는 LLM 합성 자료·증류에 대한 명시적 허용 문구가 없다. 이전 생성 모델 제안은 승인된 실행 계획이 아닌 미실행 아이디어다.
- 제출에 LoRA 어댑터만 넣으면 기본 가중치가 서버에 자동 제공되는 것은 아니다. 기본 가중치도 번들에 포함하거나 병합한 가중치로 준비하며 전체 크기를 계산한다.

평가 페이지에는 Private 100% 설명과 별도로 오래된 Public 최종 평가 문구, data/와 open/ 경로 설명이 함께 남아 있다. 이 검토로 기존 팀의 Private 평가 및 data/ 기준을 뒤집지 않는다. 언어모델 사용과 직접 관련된 위 항목만 공식 확인 근거로 추가한다.

결론: 최신 모델의 사용 자체를 금지하는 근거는 확인되지 않았다. 공개 범용 가중치 여부·공식 자료만을 이용한 추가 학습·행 독립·라이선스·실행 규격을 각각 충족해야 하며, 현재 확인된 것은 문서상 적합성 후보 여부까지다.
