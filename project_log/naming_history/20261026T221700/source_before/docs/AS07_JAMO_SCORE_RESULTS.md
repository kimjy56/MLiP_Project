# AS-07 자모 점수 분리 실험 결과

기록 시각: 2026-10-26T01:00:08+09:00

**결정: AS-06을 유지한다. AS-07 분리 점수는 실험 코드로 보존하고 기본 적용하지 않는다.**

범위: 공개 train의 외부 fold0 2,372행(한글239 / 비한글2,133), 조회 OFF. 동일한 생성 사전·fit 모델·후보 집합에서 점수 합성만 비교했다. 새 LM 학습·ZIP 생성·서버 제출은 하지 않았다.

## 구현

- AS-07/script.py의 기본 legacy 모드는 AS-06을 보존한다. separate 모드는 원래 로마자 특징을 유지하고 1.8 × (0.6 × 원자모 유사도 + 0.4 × 정규화 자모 유사도)를 한 번 더한다.
- separate 모드에서는 자모로 기존 alpha/phon/skel/tok를 덮어쓰지 않고 마지막 lattice에도 자모를 재반영하지 않는다. 따라서 해당 특징에 연동된 톤수·메타정보 게이트도 원래 로마자 값을 사용한다. 효과를 단일 보너스 항의 순수 기여로 분해한 실험은 아니다.
- 후보 검색·조회 구현은 변경하지 않았다. 후보의 개수와 정렬된 카탈로그 index 집합 해시가 모든 비교 행에서 일치했다.

## 해석

- 첫 severe 시드20261022에서는 한글6건을 고치고1건을 망쳐 순5건 증가했다. Clean/default는 예측 변경이 없었다.
- 추가 시드20261026에서는4건을 고치고5건을 망쳐 순1건 감소했다. 한 조건의 개선을 일반화할 수 없다는 근거다.
- 악화가 관측된 조건: severe_20261026.
- 이번 원본/default/severe 조건에서 한글 정답은 모두 후보 안에 있었다. 관측된 한글 차이는 검색 복구가 아닌 후보 선택 변화다. 이것으로 비공개 test에도 검색 누락이 없다고 단정하지 않는다.
- 첫 시드 결과를 본 후 추가 시드를 사전 등록해 재확인했다. 추가 결과는 설정을 바꾸지 않았지만 완전히 독립된 확증 실험은 아니다.

## 분할 이력 정정

AUDIT-AS06-LINEAGE-01에서 생성기 학습 선박4,680척/9,850행과 증강7,265쌍의 해시를 재구성했고 기존 기록과 일치했다. 학습 선박·원본·혼동 후보·모델 파일 해시 점검도 통과했다. 기존 AS-06 기록의 ‘생성기가 전체12,222행을 학습했다’는 일괄 설명은 이 기록과 맞지 않는다.

해당 생성기는 fold0을 제외하지만 folds1~4를 포함하므로 이 사전 하나를 모든 외부 fold에 재사용한 결과는 누수 없는 전체5-fold OOF가 아니다. 사전 생성 당시 모델/seed를 결합하는 별도 manifest가 없고 수동 사전과 과거 miner 전체 fit 이력도 완전히 재증명한 것은 아니다. 공개 train과 fold0은 이미 개발에 사용됐으므로 독립 최종 테스트가 아니다.

- 행별 예측·공개 train 유래 대표 오답은 Git 제외 artifacts 경로에 저장했다. 집계와 출처·해시는 실험 JSON에 기록했다. 비공개 평가 입력·개별 예측은 사용하지 않았다.
