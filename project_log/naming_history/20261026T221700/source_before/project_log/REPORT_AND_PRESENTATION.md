# 보고서·발표 근거 배치

## 보고서 권장 구성

1. **문제 정의:** 기록과 카탈로그의 관계, 후보 쌍 이진 분류, 최종 ID 선택, 행 독립 규칙.
2. **데이터 분석:** 관측 단위·결측·표기 차이·동명 선박·반복·한글 평가 비중. 근거: analysis/REPORT_8_SECTIONS.md.
3. **검증 설계:** 분할·사전 생성 시점·공식 산식·기존/새 선박 구분. 근거: 실험별 split, 데이터 해시, 누수 검사.
4. **방법:** 검색 경로, 특징, 양성/음성 구성, 손실·가중치·모델 설정. 근거: docs/MODEL_DETAILS.md와 실험 JSON.
5. **비교 실험:** 동일 조건에서 변경한 요소와 지표. 미실시 모델에는 빈칸/미측정을 표기한다. 설명서 예시 수치를 팀 결과로 사용하지 않는다.
6. **오류 분석:** 검색 누락/선택 오류와 실제 사례, 개선 가설, 재실험 결과. 근거: ERROR_ANALYSIS.md.
7. **비용과 재현:** 시간 측정 범위·장비·패키지·시드·용량·제출 검사·아티팩트 해시.
8. **한계와 결론:** 미검증 조건과 개선 방향, 채택 이유를 실측에 근거해 서술.

## 공정한 실험 비교표 양식

| 실험 ID | 변경 요소 | 분할/후보 버전 | 한글/비한글 n | 후보 포함률 H/N | 정확도 H/N | 가중 점수 | 시간과 범위 | ZIP 크기 | 해석 |
|---|---|---|---|---|---|---|---|---|---|
| 새 실험 | 계획 또는 실측 구분 | 반드시 명시 | 반드시 명시 | 미측정 허용 | 미측정 허용 | 공식 산식 | 전체/부분 구분 | 파일 해시 연결 | 근거와 가설 구분 |

서로 다른 후보·특징을 사용하면 전체 시스템 비교로 표시한다. 분류기만의 효과라고 해석하지 않는다. 실행 오류·과도한 비용 때문에 포기한 선택지도 이유를 기록한다.

## 7분 발표 구성안

| 시간 | 내용 | 필요한 자료 |
|---|---|---|
| 0:00–0:30 | 문제와 목표 | 실제 입력–카탈로그 예시 |
| 0:30–1:30 | 중요한 데이터 특성과 검증 | 한글 비중·결측·선박 그룹 분할 |
| 1:30–3:00 | 방법 | 검색→특징→학습→ID 선택 도식 |
| 3:00–5:00 | 비교 실험 | E004/E005 특징 그룹 비교 + E007/E008 검색 16조합과 reports/retrieval_combinations.png; 분류기 종류 비교는 미실시 |
| 5:00–6:00 | 대표 오답 | 검색 누락 1개·선택 오류 1개와 개선 결과 |
| 6:00–6:30 | 실행 비용·한계 | 측정 범위가 적힌 시간·용량, 미검증 조건 |
| 6:30–7:00 | 선택 근거와 결론 | 가장 중요한 실측 변화와 다음 단계 |

이는 7분 배분 제안이다. 수업 설명서의 발표 7분 + 질의응답 7분과 일치하도록 구성했다.

최신 선박명 개선의 근거는 `docs/NAME_IMPROVEMENT_RESULTS.md`에 모았다. 예를 들어
"발음 비교만 추가하면 두 번째 분할에서 하락했지만, 검색 경로까지 확장한 구성은 두 분할 모두 개선됐다"고 설명할 수 있다.
이때 검색 예산·학습 음성 구성도 달라졌고 예측 시간이 늘었다는 점을 함께 발표한다.
새 모델의 전체 학습과 ZIP 검사는 E006의 완료 여부와 실측을 인용한다.

이후 E007/E008에서 문자 n-gram 검색을 추가하고 16개 검색 조합을 두 개발 분할에서 비교했다.
최신 근거는 `docs/RETRIEVAL_COMBINATIONS.md` 및 E009이며, 37개 분류기 특징을 제거한 실험과 혼동하지 않는다.
평균으로 SNPT가 최고였지만 혼합 검증 일부에서는 하락했고 두 번째 새 선박 분할 개선은 작았다는 점을 함께 발표한다.
