# AS-02 결과 분리

공유 시 다음 폴더를 각각 올린다. 내부 실행 원본은 보존했다. 공유용 문서와 JSON의 개인 절대 경로는 제거했으므로 해당 파일의 해시는 내부 원본과 다를 수 있다. OOF·모델·제출 ZIP 내용은 변경하지 않았다. 별도 표시가 없는 데이터·실험 경로는 프로젝트 루트 기준 상대 경로이며 공유 묶음에 모든 참조 파일이 포함된 것은 아니다.

- AS-02/results: AS-02 OOF, 평가 출력, 행 독립 검사, 제출 검사. AS-02/submit_AS-02.zip은 기존 생성 ZIP의 동일 복사본이다.
- AR-02/results: 기준 OOF·평가와 fold별 학습 통계 모델. 이 모델들은 한글 점수 OFF 설정 전 공통 학습 자산이다.
- 독립_잡음/results: 잡음 비율·독립성 확인표. 독립_잡음/independent_noise.py 및 test_noise.py는 생성 함수와 검사 코드다.
- AS-02_비교자료/results: 기준과 AS-02가 함께 들어 있는 비교표·행별 fold 자료. 어느 한 모델의 단독 결과로 표시하지 않는다.

AS-02는 한글 국적·선종 점수만 OFF. G5 한글 변경22/개선6/악화7, 비한글 변경0. 대회 제출 점수는 아직 미확인이다. 새 학습·ZIP 재생성·외부 업로드는 수행하지 않았다.
