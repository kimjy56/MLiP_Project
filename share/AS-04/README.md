# 팀 공유 패키지: 실험 AS-04 (AS-SET-09 기반 집합 결정 신경망)

- **실험 ID**: `AS-04` 
- **기준 fold**: `eval_kit/folds_group5_seed42.csv` (G5-s42, 12,222행)
- **주요 특징 및 아키텍처 혁신**:
  1. **후보 집합 문맥 신경망 (CandidateSetNetwork)**:
     - 단일 쌍(Pair) 단위의 독립 점수 산출을 탈피하고, 쿼리별 후보군 간의 상대적 차이와 통계(Mean/Max Context Pooling)를 함께 인코딩.
  2. **행별 유효 후보 평균 BCE 손실 함수 (`row_bce`)**:
     - 후보 수가 많은 쿼리(30개)가 손실 그래디언트를 독식하던 불균형을 해소하고, 공식 산식의 0.7:0.3 언어 가중치를 행 단위로 부여하여 자매선(`모닝 피스`, `우찬`) 완벽 복구.
  3. **30개 후보 예산 + Hard Negative Mining (80%)**:
     - 추론 단계의 톤수 압축 필터링과 완벽히 일치시키면서도, 유사도가 높은 어려운 오답(Hard Negatives)을 집중 학습하여 고변별력 확보.
  4. **5-Fold Cross-Validation 앙상블 탑재**:
     - 5개 Fold 전체의 지식을 집약한 앙상블 추론 탑재 (각 Fold 크기 ~19 KB, 총 패키지 338 KB).
