## 2. 결과 분석 및 핵심 시사점

1. **완벽한 결정론적 재현성 검증 (Deterministic Reproducibility)**:
   - AS-02와 DEV-03의 생성된 전체 12,222행 OOF 파일 해시가 `d847008b`로 **단 1비트의 차이도 없이 100% 동일**합니다.
   - 멀티스레드 병렬화, 쿼리 뷰 사전 계산(`row['_view']`), 스레드 제한 로직을 추가했음에도 **예측 결과의 결정론적 순서와 일관성이 완벽히 유지**됨을 증명했습니다.

2. **AS-01(SPT) vs AS-02/DEV-03(SNPT) 비교 결론**:
   - 문자 n-gram(N) 채널을 추가하면 비한글 정확도가 99.918% ➜ 99.927%로 소폭 개선되지만, 한글 선박명에서 과도한 유사 후보군이 유입되어 오답이 2건 증가합니다.
   - 평가 산식의 70%가 한글 정확도에 부여되므로, **최종 대회 및 수업 제출용으로는 SPT 3채널(AS-01, 0.97918)이 가장 타겟팅되고 우수한 최적 구성**입니다.
