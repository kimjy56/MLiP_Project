# AS 담당 점검 — AR-02 기준

근거는 사용자가 지정한 Downloads/10-21_인계.md 1~6절과 받은 submit_AR-02.zip이다. 문서 내 Public 행 수·점수 역산과 리더 실측은 팀 보고이며 주최 측 확인값 또는 AS 실측으로 표시하지 않는다. 진단 제출이나 비공개 데이터 복원은 수행하지 않는다.

| 점검 대상 | AR-02 코드 위치(script.py) | 확인 결과 |
|---|---|---|
| 이름 점수와 다른 필드 상태 결합 | 712, 732 | 이름 점수 자체는 톤수·국적 결측으로 분기하지 않는다. 최종 합산에서는 메타데이터가 영향을 준다. |
| 학습 모델의 이름/결측 공동 입력 | fit_matching_model | 트리·신경망 분류기 없음. 단어/음절 대응과 국적·선종 통계표를 학습한다. |
| 후보 자체 선호 | 401~429, 771~780 | 명시적 train 선박 여부 점수는 없다. 카탈로그 사전분포 대비 조건부 국적/선종 lift를 사용한다. |
| 하드 필터 | 515, 625~662 | 톤수 창은 여러 검색 경로 중 하나다. 이름 검색 후보까지 창 밖이라는 이유로 제거하지 않는다. 후보 제한·검색 누락 가능성은 존재한다. |
| train 사전 | 575, 583, 825 | 호출부호/이름 직접 조회. 기존 use_train_lookup 스위치 존재. |
| 결측 기본값 | 557~568, 749, 771~778 | 톤수 -1 및 점수 0, 국적 UNK 점수 0, 미등록 선종 -0.35, 국적 기본 감점은 연도에 의존. |

AS 변경은 한글 행의 meta_score만 0으로 만드는 disable_korean_metadata 옵션이다. 함수 기본값 False, 모델 JSON 키 미지정 False이므로 원본 동작을 유지한다. AS 모델 설정에서만 True로 켠다. 비한글 점수·후보·이름·톤수 계산은 그대로다.

직접 조회 OFF는 문서의 최종판 요구지만 AS-02 단일 변경 비교와 별개로 영향 확인이 필요하다. 조회 ON 기준 재현 결과와 OFF 결과를 혼합해 효과를 주장하지 않는다. 공유 폴더 경로가 확인되기 전에는 로컬 결과물을 준비한다. 대회 업로드·단톡 메시지는 실행하지 않는다.

독립 잡음은 sample_id와 잡음 항목명을 SHA-256으로 조합한 별도 난수 흐름으로 선택한다. 한글 행은 변경하지 않는다. 실제 train 행의 기존 잡음은 보존하므로 최종 필드 상태가 완전히 독립이라는 보장은 없다. 6글자 이상 영문 단어만 변형할 수 있어 이름 오타 선택률과 실제 적용률을 분리한다. 톤수 결측/변동이 동시에 선택되면 결측 우선. 제공 카탈로그의 gross_tonnage를 두 입력 톤수의 변동 기준으로 사용한다. 증강은 이 AS-02 점수 변경에 섞지 않는다.
