## 독립 잡음 확인표

`independent_noise.py`: `noise_copy(train_row, target_catalog_row, seed=42)` → `(복사본 dict, 감사 flags)`.

| 잡음 선택 | 목표 | 11,031개 비한글 행 실측 |
|---|---:|---:|
| 이름 오타 | 36.5% | 36.84% |
| 톤수 결측 | 7% | 6.94% |
| 톤수 변동 | 37% | 37.26% |
| 국적 결측 | 17% | 16.97% |

실제 이름 변경률은22.41%다. 6글자 이상 영문 단어의 내부만 변형할 수 있고 두 변형이 상쇄될 수도 있어서 선택률보다 낮다. 톤수 변동 실제 적용률은34.59%다(동시 결측 우선). 원본 잡음은 보존하므로 최종 필드의 결측률과 이 표의 추가 잡음 선택률은 다르다. 한글은 변경하지 않는다. 숫자·앞뒤2글자 보존, 입력 불변, 결정성 테스트2개 통과.

항목별 독립 난수 흐름을 사용하지만 이번 유한 표본의 모든 독립성 검사를 통과한 것은 아니다. 이름 오타 선택률은 톤수 결측 없음36.89%/있음36.16%, 국적 결측 없음37.39%/있음34.13%다. 이름 선택↔국적 결측 Fisher p=0.00791로 6쌍 Bonferroni 기준0.00833에서도 차이가 검출됐다. 이를 숨기거나 통과하도록 시드를 바꾸지 않았다. 생성 절차의 독립성과 표본의 우연한 상관을 구분하며, 원본에 존재하는 상관도 자동 제거되지는 않는다. 실제 이름 변경률의 톤수 결측별 값은22.52%/20.89%다. 전체 교차표는 results/noise_independence.json.
