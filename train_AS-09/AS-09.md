# DACON 236771 선박 식별 매칭 (`AS-09`)

## 1. 주요 변경 사항
- **`IDEA_B_WORD_VARS` 미사용**: `train.csv` 오답 기반으로 수동 작성했던 단어 사전을 빈 딕셔너리(`{}`)로 변경.
- **발음 임베딩 인코더(`phonetic_encoder`) 추가**: 카탈로그 78,595척의 영문 선박명을 128차원 벡터로 미리 변환해 두고, 한글 선박명 추론 시 내적 유사도로 후보를 추가 검색.
- **자모 인덱스 및 Train Lookup 활성화**: `catalog_full_ko_map.json` 기반 자모 3-gram 검색과 `call_sign`/선박명 기반 Train Lookup 적용.
- **행 독립 추론 준수**: 모델 내 정규화는 `LayerNorm`만 사용하여 `eval_kit/check_submission.py` 통과.

## 3. 추론 과정 (`script.py`)

### 1) Train Lookup
- 입력의 `call_sign`이 `unique_callsign_lookup`에 있고 카탈로그 총톤수(GT) 차이가 12% 이하이면 해당 선박 ID 반환.
- 정규화된 선박명이 `unique_name_lookup`에 있고 총톤수 차이가 6% 이하이면 해당 선박 ID 반환.

### 2) 후보군 검색 (Stage-1)
- **비한글 선박명 (`EN_V3`)**:
  - 인코더를 실행하지 않고 기존 알파벳/자음 골격 인덱스와 톤수 구간(`query_l_win_top_osa`)으로 후보 추출.
- **한글 선박명 (`AR06`)**:
  - `catalog_full_ko_map` 기반 자모 3-gram 검색(`top_k=250`) 및 접두/접미/어절 인덱스 검색.
  - 로마자 변환 및 톤수 구간($\pm 9.8\%$) 후보 추출.
  - `retrieve_dense_candidates()`: 입력 선박명 벡터와 카탈로그 전체 벡터(`78595×128`)를 내적하여 상위 35개를 후보군(`cand_set`)에 추가.

### 3) 후보 점수 계산 (Stage-2)
한글 후보 선박은 아래 점수의 합(`total_score`)이 가장 높은 선박을 선택:
```text
total_score = name_score + num_score + ton_score + meta_score + dense_score
```
- `name_score`: 로마자(`sim_alpha`), 발음(`sim_phon`), 자음 골격(`sim_skel`), 어절(`sim_tok`), 자모(`sim_jamo`) 유사도 가중합.
- `num_score` / `ton_score`: 선박 번호 일치 여부 및 톤수 오차 구간별 점수.
- `meta_score`: 선종(`vessel_type`) 및 국적(`flag_name`) 전이 확률 점수.
- `dense_score`: 인코더 유사도(`dense_sim`), 순위 역수(`1/rank`), 상위 35개 내 표준점수(`dense_zscore`), 1-2위 점수 차이(`dense_margin_top1`)의 가중합.

## 4. 인코더 모델 (`phonetic_encoder`)
- **베이스 모델**: `docuracy/symphonym-v8` (`CC-BY-4.0`). 전체 문자 사전에서 한글 자모, 영문 알파벳, 숫자 등 148개 토큰만 남기고 나머지 문자 임베딩 행 제거.
- **입력 구성**:
  1. `Primary`: 한글 자모 분해 / 영문 원문
  2. `Secondary`: 한글 로마자 변환(알파벳 독음 포함) / 영문 발음 축약(`en_to_phonetic`)
  3. `Tail`: 첫 어절(선사명)과 숫자를 제외한 뒷단어
- **구조**: `Embedding(104d) -> Linear(128d) -> SyllableConvBlock(k=3, 5) -> 2-Layer BiLSTM(256d) -> SelfAttention -> Pooling -> Projection(128d) -> GatedMultiViewFusion`.
- **학습**: `SupConCosFaceHardLoss` ($\tau=0.05, m=0.08, \gamma=0.20$), 첫 어절이 같은 다른 선박 2척 + 전체 카탈로그 내 유사도 상위 오답 2척을 하드 네거티브로 사용.
