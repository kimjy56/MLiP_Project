# 데이터 분석 참고 — 팀 v3에서 분리

출처: 사용자가 첨부한 TEAM_RULES.md v3(2026-10-18) §1·§2. 아래 수치는 원문에 보고된 값이며 이번 문서 수정에서 재계산하지 않았다. 우리 작업공간의 E001~E010 실측과 혼합하지 않는다. 일부 구성 수치가 일치하더라도 개별 분석 전체가 검증된 것으로 보지 않는다.

## 데이터 구조

- train: `sample_id, vessel_name, call_sign, gross_tonnage, international_gross_tonnage, flag_name, vessel_type, arrival_year, target_vessel_id`.
- catalog: `vessel_id, vessel_type, vessel_name, size, unit, deadweight_tonnage, gross_tonnage, flag_name`.
- test의 정확한 구조·전체 크기는 서버에서 제공되는 명세를 따른다. sample_submission의 3,000행을 전체 테스트 크기로 간주하지 않는다.
- UTF-8 BOM을 처리할 수 있도록 `encoding='utf-8-sig'`를 권장한다.

## 팀 참고 점수

v3는 동일 fold·전체 12,222행 OOF의 수치라고 설명한다. 원본 OOF·평가기·설정이 확보되면 재현하고 출처를 연결한다. 현재 모델과 직접 비교하거나 공식 리더보드 점수로 표시하지 않는다.

| v3 방법 | 한글 | 비한글 | 가중 |
|---|---|---|---|
| 주최 RF baseline E00, 비교값 10개 | 26.2% | 98.04% | 0.4775, CI [0.4460, 0.5101], evaluate.py 1.0 |
| 자음 골격 + 톤수 ±5% | 59.7% | 미기재 | 미기재 |
| 학습 자모 대응: 이름만 / 제원 추가 | 98.6% / 99.7% | 미기재 | 미기재 |
| TF-IDF 이름만 / OSA / 오타 모델+톤수 | 미기재 | 97.96% / 99.52% / 99.89% | 미기재 |

분석을 갱신할 때 실행 코드·데이터 해시·집계 정의·분모·측정 시점·실험 ID를 함께 기록한다. 수치가 없는 칸을 0으로 채우지 않는다.
