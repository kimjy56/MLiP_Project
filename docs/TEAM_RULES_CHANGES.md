## 문서 변경 당시 완료되지 않은 일

- 팀 eval_kit·고정 fold 수령, 평가기 자체 검사/E00 재현, 팀 5-fold 재평가.
- 기존 추론 코드의 조회 통합 스위치 및 open/ fallback 구현.
- Ubuntu/L4에서의 GPU·공식 서버 실행 확인. E010은 Python/패키지 일치와 일부 CPU 입력 호환성 검사다.
- 최신 공식 공지·원본 업로드·사전 조회 관련 답변 확인, 팀 접두 ID 배정.

위 항목은 규칙 수정과 별개이며 이번 작업에서 실행하지 않았다. 모델·과거 실험 결과·ZIP도 변경하지 않았다.

후속 코드 작업에서 조회 통합 스위치, `open/` fallback 및 고정 fold OOF 실행 경로를 구현했다.
구현·검사 범위와 실제 팀 검증에 필요한 파일은 [코드 적용 안내](TEAM_RULES_IMPLEMENTATION.md)를 참고한다.
